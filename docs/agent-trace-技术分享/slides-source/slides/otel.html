OpenTelemetry：我们用到的部分

OpenTelemetry（OTel）是 CNCF 的可观测性开放标准，统一规定 trace、metric、log 的数据模型、SDK 与传输协议 OTLP。它最初用于微服务的分布式追踪，即记录一个请求跨多个服务的调用链；GenAI 语义约定把同一套模型扩展到 LLM 与 agent 调用。
