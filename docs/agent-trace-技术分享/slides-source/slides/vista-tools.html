VISTA 的 8 个工具与系统提示

工具作用输入 → 返回
play执行一个动作ACTION1–7 或 RESET，点击另带坐标 → 元数据 + 本回合最后一帧
inspect回看画面1–16 个视图（回合号、帧号、区域）→ 放大后的截图

read_guide

read_working
write_working		本关草稿全文读写，至多 16 KB，过关时归档清空

系统提示（全文）

Visual game task. Complete the game with as few game actions as possible. Build and use a compact, revisable model of the game and its current state. Update it as new evidence changes what is supported. Before each play, briefly state what you expect to see. Afterward, briefly state all visible changes, expected or not. Keep concise, durable, revisable game understanding in GUIDE.md; use WORKING.md as a scratchpad when useful.

  • 只有 play 自动返回画面；更早的画面、动画帧和动作记录需要模型按回合号主动查询
  • 内置工具全部禁用，模型不能读文件、不能执行代码
