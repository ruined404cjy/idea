存储侧实验

实验目的工作结果
摄入对账trace 从产生到入库不丢失、不重复经 Collector 写入 openGauss，发送清单与库内数据做差集10 traces / 69 spans 全部入库，差集为 0
列存写入持续追加写入的吞吐与完整性50 万 spans 写入 xstore 列存，exporter 多路并行无丢失；8 路并行 10,316 rows/s
查询去重OTLP 重试会产生重复 span，查询须得到唯一结果只追加、不建主键，查询时按 (trace_id, span_id) 取最新版本先过滤再去重：约 4 s 降至 141–257 ms
图查询按调用关系取整棵 trace 树，做跨 trace 关联span 父子关系存为图的边，用 Cypher 查询，与列存对比取整树快 23 倍；取 payload 慢 1.5 倍，图只做关系查询层
payload 存储prompt / response 等长文本占主要体积对比同表、拆表、外置等布局；分析 3,600 条真实轨迹每次 LLM 调用记录完整上下文时，存储量是只记录增量的 53.15 倍
