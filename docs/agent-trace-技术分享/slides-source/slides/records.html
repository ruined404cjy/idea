基础概念

Chat、Trace 与 Memory

Chat 记录

线性文本 · 按会话

记录什么

系统提示、用户消息、模型回复、工具结果，即模型实际看到的上下文

用途

继续对话、人工翻阅；过长时被压缩或截断

Trace

结构化执行记录 · 按运行

记录什么

每次 LLM 调用与工具调用的起止时间、父子关系、状态、模型与 token、输入输出

用途

可观测性、评估、失败归因、回放与续跑

Memory

提炼后的条目 · 跨任务

记录什么

从历史执行中提炼、持久保存、在后续任务中注入上下文的经验

用途

避免重复错误、复用已验证的做法、遵循用户偏好

chat 是 trace 中 LLM 调用的输入输出部分；现有记忆生成工作大多先把 trace 转为纯文本，父子结构、耗时和状态码随之丢失。
